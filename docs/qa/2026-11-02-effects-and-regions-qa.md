# 효과·모양 기능 QA 기록 (2026-11-02)

대상: 브랜치 `spec/effects-and-regions` (블러·단색 효과, 배경 효과, 타원·다각형 수동 영역). 스펙: `docs/superpowers/specs/2026-11-02-effects-and-regions-design.md`. 아래는 모두 2026-11-02에 직접 측정·확인한 값이다. 확인하지 못한 항목은 "(미확인)"으로 표시했다.

## 1. 렌더 속도

- 환경: 워커 docker 이미지, 로컬 Mac.
- 작업: 1080p, 24fps, 115초, 2,760프레임, 트랙 139개(학생들이 걷는 테스트 영상).

| 조건 | fps |
|---|---|
| 기본 모자이크 | 160.0 |
| 모든 영역 블러 + 다각형 1 + 타원 1(색상) — 최적화 전 | 3.7 |
| 같은 조건 — 축소 해상도 블러 적용 후 (커밋 `1e17b07`) | 48.6 |
| 배경 블러 | 63.0 |
| 배경 모자이크 | 66.2 |

## 2. 블러 강도 하한

- 얼굴 사진에서 강도 1의 라플라시안 분산 비율(블러/원본) = 0.000670 (기준 < 0.02).
- 축소 해상도 블러와 전체 해상도 블러의 잔여 디테일 비율 = 0.98 (기준 ≤ 1.5).

## 3. 렌더 프레임 확인 (프레임 100)

- 얼굴이 블러 처리됨.
- 타원 영역이 선택한 색으로 채워짐.
- 다각형 영역은 그린 삼각형 안쪽만 블러 처리됨.

## 4. 브라우저 확인

Chrome, 미리보기 창, 뷰포트 1600x1000. 저장·전파 요청은 가로채서 로컬 데이터는 바뀌지 않았다.

- 기본 블러: 마스크 안 반투명 픽셀 0개.
- 배경 블러: 처음·마지막 canvas 행의 알파가 231이었다(콘텐츠 사각형이 소수 폭 519.75px이기 때문). 커밋 `3d55478`에서 바깥쪽 반올림으로 수정, 수정 후 반투명 픽셀 0개.
- 다각형 도구: 클릭 3번 + Enter로 shape `"polygon"`과 [0,1] 범위 points가 저장됨. 전파 요청에는 바운딩 박스만 실림. 포커스가 도구 버튼으로 돌아옴.
