# 얼굴·머리 찾기 실험 정리 (2026-11-09 ~ 11-10)

모자나 마스크로 가린 얼굴까지 가리려면 어떤 방법이 좋은지, 지금까지 시험한 방법과 결과를 한곳에 모은 문서입니다. 더 자세한 근거는 [머리 검출기 검토](2026-11-09-head-detector-options.md)에 있습니다.

이 문서의 실험은 모두 **시험용으로만** 돌려 본 것이고, 실제 서비스 코드는 바꾸지 않았습니다.

## 한눈에 보기

- 지금 서비스는 영상 속 머리의 **35%만** 가리고 있습니다. 특히 모자·마스크를 쓴 사람을 많이 놓칩니다.
- 이미 공개된 모델 중에서는 **OWLv2**와 **Grounding DINO**가 가린 머리를 처음으로 잘 찾았습니다. 하지만 너무 느려서 서비스에 바로 쓸 수 없습니다.
- 그래서 느린 모델이 정답을 대신 표시해 주고, 그걸로 **빠른 작은 모델을 새로 학습**시켰습니다. 이 작은 모델을 지금 서비스 방식에 함께 넣었더니 **가려지는 머리가 35% → 69%로 약 2배**가 됐습니다. 엉뚱한 곳을 가리는 횟수는 지금과 비슷합니다.
- 다만 아직 영상 한 개로만 확인했고, 학습에 쓴 영상은 상업적으로 쓸 수 없는 영상이라 검증과 정리가 더 필요합니다.

## 용어 풀이

| 용어 | 뜻 |
|---|---|
| 찾은 머리 비율 | 정답으로 표시해 둔 머리 중 몇 %에 박스를 그렸는지. 높을수록 좋습니다 |
| 잘못 그린 박스 (한 화면당) | 머리가 아닌 곳에 그린 박스가 화면 한 장에 평균 몇 개인지. 낮을수록 좋습니다 |
| 점수 기준 | 모델은 박스마다 "머리일 확률" 같은 점수를 붙입니다. 기준을 낮추면 더 많이 찾지만 엉뚱한 박스도 늘어납니다 |
| 조각 확대 | 화면을 여러 조각으로 잘라 크게 키운 뒤 조각마다 다시 찾는 방법. 작은 얼굴은 더 잘 찾지만 몇 배 느려집니다 |
| 스승 모델 / 학생 모델 | 느리지만 정확한 모델(스승)이 영상에 정답을 자동으로 표시하고, 그 표시로 빠른 작은 모델(학생)을 학습시키는 방식입니다 |
| 추적 | 프레임마다 찾은 박스를 같은 사람끼리 이어 붙이는 단계입니다 |
| 유지 | 사람을 잠깐 놓쳐도 박스를 잠시 그대로 두는 규칙입니다. 지금은 0.5초입니다 |
| 연결 | 같은 사람이 잠깐 끊겼다 다시 나오면 그 사이도 가리는 규칙입니다. 지금은 최대 2.5초입니다 |
| 자동 해제 | "얼굴이 아닐 가능성이 높다"고 판단한 박스를 분석 끝에 자동으로 가림 해제하는 규칙입니다 |

## 3. 서비스 방식에 그대로 넣었을 때 (채점 기준 A, 최종적으로 가려진 결과)

모델 하나만 돌린 결과가 아니라 추적, 유지, 연결, 자동 해제까지 모두 거친 뒤 **실제로 가려진 결과**입니다.

| 설정 | 가려진 머리 | 엉뚱한 곳을 가린 수 (한 화면당) |
|---|---|---|
| **지금 서비스** (YuNet, 유지 0.5초, 연결 2.5초, 자동 해제) | **35%** | **4.0개** |
| YuNet + 작은 모델, 규칙은 그대로 | 81% | 32개 (대부분 유지·연결 규칙이 남긴 박스) |
| YuNet + 작은 모델, 유지 0.15초로 줄이고 연결 끔 | 77% | 9.4개 |
| 위 설정 + 3번 이상 찾은 사람만 가림 | 73% | 5.8개 |
| **위 설정 + 5번 이상 찾은 사람만 가림** | **69%** | **4.3개** |
| 위 설정 + 8번 이상 찾은 사람만 가림 | 62% | 3.1개 |

→ 엉뚱한 곳을 가리는 횟수는 지금과 비슷하게 두면서, 가려지는 머리는 **약 2배**가 됩니다.

지금의 긴 유지·연결 규칙은 YuNet이 사람을 자주 놓치는 것을 메우려고 만든 것입니다. 사람을 잘 찾는 모델과 함께 쓰면 오히려 엉뚱한 박스를 크게 늘리므로, 함께 쓸 때는 규칙을 줄여야 합니다.

## 4. 목표 변경 후 다시 잰 결과: "맨얼굴만 가린다" (2026-11-10)

목표를 "머리 전체"에서 **"맨얼굴만 가린다"**로 바꿨습니다. 복면·마스크로 가린 얼굴과 뒤통수는 안 가려도 됩니다.

- 채점 기준 A의 머리 268개를 다시 봤습니다. 이목구비가 보이는 맨얼굴은 **19개**이고 모두 제니입니다. 이 영상의 댄서들은 전원 복면이나 마스크를 썼습니다.
- 가려도 그만, 안 가려도 그만인 머리(복면·마스크·뒤통수)는 점수에 넣지 않았습니다. 대신 몇 개를 가렸는지 따로 셌습니다.

| 설정 | 가려진 맨얼굴 | 안 가려도 되는 머리를 가린 수 (한 화면당) | 엉뚱한 곳을 가린 수 (한 화면당) |
|---|---|---|---|
| **지금 서비스** | **18/19 (95%)** | 3.3개 | 3.8개 |
| 지금 서비스 + 작은 모델 (유지 축소) | 19/19 (100%) | 13.4개 | 9.1개 |
| 위 설정 + 5번 이상 찾은 사람만 | 18/19 (95%) | 9.2개 | 4.0개 |
| (참고) YuNet 모델만 단독 | 17/19 (89%) | 1.9개 | 0.3개 |

지금 서비스가 놓친 맨얼굴 1개는 넓은 장면의 작은 제니 얼굴입니다. YuNet은 찾았지만 "얼굴이 아닐 가능성이 높다"는 판단으로 자동 해제된 경우였습니다.

**이 결과가 뜻하는 것**
- 맨얼굴 기준으로는 지금 서비스도 이미 대부분 가리고 있습니다. 머리를 찾는 작은 모델은 이제 **필요 없습니다.** 오히려 안 가려도 되는 머리를 많이 가립니다.
- 남은 과제는 **불필요한 가림 줄이기**입니다. 한 화면에 약 7개(복면 댄서 3.3개 + 엉뚱한 곳 3.8개)이고, 맨얼굴은 계속 가려야 합니다.
- 예전에 "복면 쓴 댄서가 드러난다"는 이유로 **기각했던 규칙들을 다시 볼 만합니다.** 예를 들어 잠깐 나온 박스를 앞뒤 장면에서 다시 확인하는 규칙(엉뚱한 가림 69→56곳)입니다. 이제는 복면 댄서가 드러나도 괜찮기 때문입니다.
- 주의: 맨얼굴이 19개뿐이고 모두 같은 사람입니다. 맨얼굴이 많은 영상(paris 거리 영상 등)으로 함께 재야 합니다.
