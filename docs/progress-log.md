# 진행 로그

업로드한 녹화 영상에서 얼굴을 자동 검출·추적해 기본 전부 모자이크하고, 사람별로 보이게 하거나 위험 구간을 검수한 뒤 오디오가 보존된 결과를 내려받는 사내 웹 스튜디오(R1 프로토타입)의 시도 기록이다.

## 현재 상태

기준일: 2026-11-05, 최신 기능 커밋 `fc1fa71`.

**동작하는 것**
- 업로드 → 정규화 → YuNet 검출 → ByteTrack식 추적 → 검수 항목 생성 → 렌더(오디오 보존) 전체 흐름 (api / web / worker, docker compose).
- 사람별 보이기/가리기, 수동 박스, 트랙 분할, 확인 필요 항목 검수, 되돌리기·다시 하기, 타임라인 확대, 모자이크가 적용된 필름스트립 (`b9d87aa`).
- 흩어진 트랙 연결(`link.py`)과 성장 전 박스 기준 교차 검사 (`d78df25`). 워커 테스트 93개 통과, 워커 컨테이너 재빌드 완료.
- 10개 클립 테스트 영상(`test-media/pexels-students-10clips-1080p.mp4`, 1분 55초, 1080p, git 제외)에서 트랙 139개, 검수 항목 144개.
- 영상에서 모자이크를 눌러 그 조각만 가림 해제(X 버튼, Ctrl+Z로 되돌리기).
- "다시 분석" 버튼: 원본으로 최신 기준 재검출. 사람별 편집은 초기화, 직접 그린 영역과 효과 설정은 유지.
- 얼굴 모양(타원) 블러, 가장자리만 은은하게 흐려짐. 효과를 지정하지 않은 작업은 블러가 기본.

**열려 있는 것 (사용자 결정 또는 외부 확인 대기)**
- 같은 사람 찾기 기능: "이 사람 찾기" 방식(B)으로 설계 중, 설계 승인 대기. 버튼을 눌렀을 때만 실행, 임베딩 미저장.
- 블러 효과: 효과·영역 브랜치를 main에 병합하고 앱을 다시 빌드함. 기본 효과·배경 효과에서 블러 선택 가능(브라우저에서 확인).
- 검수 항목: 위험 높은 항목만 필수(얼굴 40px 이상, 3프레임 이상, 의심 아님), 나머지는 참고. Pexels 새 업로드 기준 필수 30건·14구간, 참고 69곳. 5초 구간 묶음 적용.
- 업로드 화면: 참고 편집기와 같은 편집기 모양 첫 화면, 파일을 놓으면 바로 작업 화면으로 이동. 기존 작업은 상단 "내 작업" 목록.
- 학습 데이터 라이선스: WIDER FACE(YuNet 학습 데이터)가 CC BY-NC-ND 4.0으로 표기됨. 법무 검토 진행 중이며 결과 미확인.
- 얼굴 검출기 교체 여부: 점수·랜드마크로는 오탐을 못 거름. 대체 후보는 아직 없음(BlazeFace 계획은 폐기).
- 1080p 5분 영상 처리 시간, 긴 영상의 `tracks.json` 크기: 측정하지 않음(README 기준).
- "얼굴 아닐 수 있음" 묶음: 타일 일괄 해제, 타일 클릭 시 해당 위치로 이동(`fc1fa71`). 크롭 재검출 실패 + 사람 머리 없음은 분석 끝에 자동 가림 해제(`5dc7db3`). 붐비는 거리 영상에서는 진짜 얼굴이 해제될 위험이 있음(샘플 100개 중 최소 8개), 렌더 전 "보임" 목록 확인 필요.
- 짧은 검출 공백 메우기(측면 얼굴, 가려진 얼굴): `7c6cc8d`. Pexels 영상 외 영상에서는 아직 확인하지 않음.
- 원격 저장소에 push하지 않음(로컬 main이 앞서 있음).

### 2026-11-05 — 사람이 없는 검출도 "얼굴 아닐 수 있음" 묶음에 표시 (체크 없이)

## 로그 작성 규칙

새 항목은 맨 아래에 추가한다(오래된 것이 위, 최신이 아래).

```
### YYYY-MM-DD — <짧은 제목>
- 목표:
- 시도한 것:
- 결과: (숫자와 표본 크기, 어떤 영상인지)
- 결정·이유: (버린 방법과 이유 포함)
- 커밋: (짧은 SHA, PR 번호. 없으면 "없음")
```

- 형용사보다 숫자를 쓴다. 표본 크기와 영상 종류를 같이 적는다.
- 실패하거나 버린 시도도 이유와 함께 남긴다.
- 커밋과 PR을 링크하거나 짧은 SHA로 적는다. 이력을 다시 쓴 경우 현재 SHA를 쓴다.
- 확인하지 못한 내용은 추측하지 말고 "(미확인)"으로 표시한다.
- 공개 저장소이므로 타사 제품명, 비밀번호, 토큰, `.env` 값, 개인 이메일을 쓰지 않는다. 필요하면 "타사 영상 편집 서비스"라고 쓴다.
- 현재 상태 절도 함께 갱신한다(최신 커밋, 열린 결정).
